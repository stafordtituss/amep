# Contributing to AMEP

Thank you for helping. Contributions of every size are welcome: a typo, a question about the specification, a new vector, an implementation in another language, or a research result. Open problems are listed in [`RESEARCH.md`](RESEARCH.md); smaller starting points are labelled `good first issue`.

## Ways to contribute

- **Ask or discuss.** Use GitHub Discussions for questions and ideas, and issues for concrete bugs or proposals.
- **Report an ambiguity.** If two readings of the specification are possible, open an issue quoting the text. Ambiguities are bugs.
- **Add a vector.** Vectors are generated by `verifier/python/amep_verifier.py` (core suite) and `interop/w3c-agent-identity/delegation-continuity/generate.py`. Add a case to the generator, regenerate, and commit both.
- **Implement AMEP.** A verifier or producer in another language is the most valuable contribution. Run it against `vectors/` and tell us what was unclear.
- **Propose a change.** Open an issue first. Larger changes become an `AMEP-Proposal-N` document in `proposals/`.

## Rules for changes

1. **Every normative change adds vectors**: at least one positive and one must-reject vector that distinguish the new behaviour from the old (spec Section 15.3).
2. **Both verifiers must agree** on every vector, on the outcome and the deciding invariant.
3. **The suite is generated, not edited by hand.** Test keys are deterministic, so regeneration is byte-for-byte reproducible and CI checks it.

## Checks to run before a pull request

From the repository root:

```bash
python -I verifier/python/amep_verifier.py && git diff --exit-code -- vectors
python -I verifier/python/amep_verifier.py --check vectors
node verifier/typescript/amep_verifier.mjs vectors
node verifier/browser/build.mjs && node verifier/browser/test_page.mjs
python tools/validate_schemas.py
python -I tools/vector_index.py --check
python -I paper/eval/mutation.py --check
```

For the MCP server: `PYTHONPATH=packages/python/src:packages/mcp/src python -m unittest discover -s packages/mcp/tests`.
